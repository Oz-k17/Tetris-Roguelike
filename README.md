# 氷窟スタック

凍った洞窟を降りていく、ローグライク型の落ちものパズル。

- 4つのクラス（守護者・癒し手・鼓手・剣士）から選んで潜る
- レベルアップで遺物を選び、ボスを倒したら行商人で買い物
- 冷気とボスの強撃でHPが削られていく。地下8階のボスを倒せば踏破
- 最大4人のパーティで、同じボスをみんなで削れる

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（スマホ対応）。

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | ← → | ◀ ▶ |
| 回転 | Z / X（↑） | ⟲ ⟳ |
| ソフトドロップ | ↓ | ▼ |
| ハードドロップ | Space | ⤓ |
| ホールド | C | HOLD |
| 一時停止 | P | II |

## みんなで遊ぶ

1. タイトルの「みんなで潜る」を押す
2. ひとりが「部屋を作る」を押し、表示された4桁の番号を仲間に伝える
3. 仲間は番号を入れて「入る」
4. 全員そろったら、部屋を作った人が「出発」

通信は [PeerJS](https://peerjs.com/) を使った端末どうしの直接通信です。サーバーの用意やアカウント登録は要りません。部屋を作った人が抜けるとパーティは解散します。学校や会社のネットワークではつながらないことがあります。
